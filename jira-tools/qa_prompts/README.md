# QA Prompt Library

76+ prompts for API testing, security testing, automation, performance, and UI testing. Part of the Jira QA Automation Tools — use with ticket data to generate test cases and QA docs.

**Source:** [QA Prompt Dictionary](https://promptqa.vercel.app/library)

- `qa_prompt_dictionary_library.md` — Full library with all prompts
- `prompts_data.json` — Raw prompts in JSON format

Use these prompts with AI tools (ChatGPT, Claude, etc.) to generate test cases, automation scripts, and QA documentation. Combine with ticket history and regression reports for end-to-end QA workflows.
