# TC-01 - Apply valid coupon updates total

> Synthetic example for portfolio demonstration.

| Field | Value |
| --- | --- |
| ID | TC-01 |
| Priority | P1 |
| Type | UI + API |
| Pre-condition | Cart contains 1 x ACME-SKU-001 ($25.00) |

## Steps

1. Navigate to the payment page.
2. Enter coupon code `WELCOME10`.
3. Click `Apply`.

## Expected

- Order total changes from `$25.00` to `$22.50`.
- Success badge appears next to the coupon input.
- API response `POST /api/demo/coupons/apply` returns `200` with `discountApplied: true`.
