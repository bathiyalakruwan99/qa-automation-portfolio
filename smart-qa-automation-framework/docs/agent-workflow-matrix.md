# Agent Workflow Matrix

Which agent groups participate at each QA stage.

| QA Stage                     | Primary Agent Group                                | Example Output                                |
| ---------------------------- | -------------------------------------------------- | --------------------------------------------- |
| Requirement understanding    | Requirement and discovery agents                   | Acceptance criteria, risk list, open questions |
| Test strategy                | Strategy and architecture agents                   | Coverage plan, test layers, priority matrix   |
| Flow discovery               | Browser, DOM, flow, and domain agents              | User journey map, dependency map              |
| Test data planning           | Test-data and planning agents                      | Positive, negative, edge-case data matrix     |
| Test automation              | Playwright, BDD/POM, API, Postman, and k6 agents   | Reusable automation design and validation assets |
| Test execution               | E2E runner and execution agents                    | Run result, screenshots, traces, reports      |
| Investigation                | Bug-hunt, network, pattern, and healing agents     | Root-cause direction and next action          |
| Reporting                    | Defect writer and report writer agents             | Defect report, test summary, quality report   |
| Release assessment           | Release-gate and release-management agents         | Go / monitor / hold recommendation            |
| Learning                     | Memory curator and learning agents                 | Verified reusable QA knowledge update         |
