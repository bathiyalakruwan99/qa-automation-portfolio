# Confidentiality and Sanitization Policy

This portfolio is a **public** repository. The rules below apply to every file in this repo.

## Never include

- Real customer data, personal data, or business contact data.
- Real production URLs, API hosts, internal endpoints, or environment names.
- Credentials, tokens, API keys, certificates, or `.env` files.
- Internal screenshots, internal Jira tickets, internal Figma boards, or proprietary diagrams.
- Real production payloads, real production GPS coordinates, or real customer Excel exports.
- Proprietary business logic copied verbatim from any employer.

## Always include

- A clear `Confidentiality Note` section in every project README.
- A clear marker on sample data: `demo`, `sanitized`, or `reference implementation`.
- Public demo targets only (e.g. `demo.playwright.dev`, `reqres.in`).
- Generated or fictional names and IDs.

## Code and frameworks

- Code in this repo is **inspired by** patterns I use professionally; it does not reproduce any employer's codebase.
- Where a technique (POM, fixtures, BDD, k6 stages) is industry-standard, it is presented as such.

## Reporting an issue

If something in this repository looks confidential, please open an issue or contact me at bathiyalakruwan99@gmail.com and I will remove it.
