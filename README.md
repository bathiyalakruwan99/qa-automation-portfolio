## Smart QA Agent OS Overview

Smart QA Agent OS is an evolving, AI-assisted QA operating model that supports QA work without replacing QA judgement. It separates capability areas by maturity (Actively Used, Implemented Prototype, In Development, Learning, and Planned) so that nothing is overstated, and it keeps a human QA engineer responsible for every final decision.

It covers exploratory QA support, requirement and test planning, browser and flow discovery, QA knowledge capture, Playwright test design, locator-healing investigation, and a growing set of execution, API, performance, and release-gate workflows. Locator/test-healing is used as a guided, human-reviewed investigation workflow, not as a fully autonomous runtime auto-healer.

See the [`smart-qa-agent-os/`](smart-qa-agent-os/) directory for the full operating model, architecture, and synthetic examples.
