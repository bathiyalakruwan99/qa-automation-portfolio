# Data folders (portfolio – no client data)

This project uses a structured layout:

- **input/** – Job Master Excel files (add your own for testing)
- **exports/** – Generated exports
- **samples/** – Sample job ID lists (csv, txt, xlsx)
- **uploads/** – Web app uploads
- **downloads/** – Web app downloads
- **reports/** – Reports

No client or company data is included in this portfolio copy. Use your own files when running the apps.
